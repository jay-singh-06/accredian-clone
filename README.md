npm install
4.Run the development server:

5.Open your browser and visit:
http://localhost:3000

💡 Approach Taken

The goal was to replicate the UI and behavior of the Accredian website as closely as possible using modern frontend practices.

Key decisions:
Built using Next.js (App Router) for structured development
Used Tailwind CSS for fast and responsive styling
Followed a component-based architecture to keep code modular and reusable
Structure:

Each section of the website was built as a separate component:

Navbar (with scroll tracking)
Hero Section
Stats Section
Clients Section
Accredian Edge
Domain Expertise
Tailored Course Segmentation
Who Should Join
CAT Section
How It Works
FAQ Section (accordion)
Testimonials (slider)
Footer
Features implemented:
Scroll-based active navbar highlighting
Smooth scrolling navigation
Fully responsive layout
Interactive components like:
FAQ accordion (expand/collapse)
Testimonials slider (with dots navigation)
Reusable UI components for consistency

The focus was on writing clean, readable, and maintainable code while closely matching the original design.
